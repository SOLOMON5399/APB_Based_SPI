# APB_Based_SPI# APB Based SPI Controller

## Overview
This project implements an APB-based SPI Controller using Verilog.

## Features
- APB Slave Interface
- SPI Transmitter/Receiver
- Baud Rate Generator
- Shift Register
- Slave Select Logic

## Tools Used
- Verilog
- Vivado Simulator

## Verification
Testbenches were developed for:
- Baud rate generator
- Shift register
- APB slave interface
- Top module

## Applications
- SoC communication
- Embedded systems
- Peripheral interfacing
